The feed engine
behind your reader.

Kiki fetches RSS and Atom feeds on a polite schedule, stores their entries, filters and tags them with plugins, and serves it all over a small HTTP API. Build a reader on top, sync it into the one you already use, or just point scripts at it.

Get started Read the guide 
$ kiki init
$ kiki opml import subscriptions.opml
$ kiki web
# reading at http://localhost:8080

Polite fetching

Honours caching headers and Retry-After, backs off from errors, and learns which feeds rarely change.

Fetch settings

Lua plugins

Hide sponsored posts, tag entries by topic, strip tracking parameters, or write your own handlers.

Plugins

Built for clients

Tags instead of fixed read/saved flags, monotonic entry IDs, and batch endpoints make syncing straightforward.

The HTTP API

Locked down

Serves only on a Unix socket, and sandboxes itself with Landlock and seccomp, with fetching and plugins in separate processes.
